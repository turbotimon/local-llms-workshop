# 01b – Decision models

Decision models answer yes/no, pick a label or give a score – with probabilities.

- Docs: https://docs.ollama.com/capabilities/decision
- Models: https://ollama.com/search?c=decision
- Endpoint: http://localhost:11434/v1/systemone

## 1. Download a decision model

IMPL: Find a decision model in the docs and download it with `ollama pull <model>`.

## 2. Test it out

IMPL: Read the docs and send a request to the decision model with curl.
