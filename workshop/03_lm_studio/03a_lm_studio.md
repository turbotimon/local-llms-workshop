# LM Studio

Note: LM Studio recently released **"LM Studio Bionic"**. While LM Studio is/was only a model runner, LM Studio Bionic brings some more capabilities like Agents. Both will work for this workshop (the UI is slightly different, but you should be able to follow along). There is also a product called **llmster**, which is the headless version e.g. for servers.

## 1. Install

Follow the instructions to install [LM Studio](https://lmstudio.ai/download) on your device.

## 2. Pull a model

In LM Studio, search and download a model of our choice. It can be the same as you used for Ollama.

If you can, again choose a model that has *Tools*, *Thinking* and *Vision* capabilities.

## 3. Run the model

Go to the chat and run the model.

Explore the settings in the UI and try out the following:

- Set a system prompt
- Change the temperature or top-p setting

## (4. Optional)

Explore more functions of LM Studio form their [documentation](https://lmstudio.ai/docs/app).

For example:

- Try out "ML Link" to connect your mobile device to your computer
- Try out multimodal input (vision)
- Integrate web search
- Create a model.yaml
- Create structured (json) output
- Chat with documents (pdf, txt, docx, etc.)
